# ff-news-calendar

Forex Factory's weekly calendar, filtered to **medium + high impact USD and EUR** events.
A GitHub Action refreshes it every hour.

Subscribe in Apple Calendar (File → New Calendar Subscription):

https://abdul-moiz16.github.io/ff-news-calendar/ff_usd_eur.ics

Change the filter by editing `KEEP` / `IMPACTS` in `filter.py`.
